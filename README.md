# WomenSafe 🛡️

A Java Swing desktop application designed for women's safety. Features include:
- User and Admin Authentication
- Emergency SOS with Live Location (via Google Maps link)
- Emergency Contact Email Alerts (JavaMail)
- Live Location Sharing

## Technologies Used
- Java (Swing UI)
- MySQL (JDBC)
- FlatLaf (Modern UI Framework)
- JavaMail API
- JSON / IP-API

## How to Run
1. Clone the repository.
2. Import the project into VS Code or Eclipse.
3. Create a MySQL database named `womensafe` and import the SQL file.
4. Update the database credentials in `DatabaseConnection.java`.
5. Update the email credentials in `EmailUtil.java`.
6. Run `Main.java`.
